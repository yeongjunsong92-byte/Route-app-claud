# Route 지도 화면 레퍼런스 메모

## 확인한 패턴

- **Google Maps형 비모달 하단 시트:** 지도 위의 장소 컨텍스트를 유지한 채 장소 정보와 다음 행동을 제공한다. Route에서는 장소 카드·저장·코스 추가를 여기에 둔다.
- **확장 가능한 정보 계층:** 축소 상태는 지도 탐색을 방해하지 않으며, 사용자가 필요할 때만 끌어올려 장소 목록과 상세 정보를 확인한다.
- **검색 중심 상단 영역:** 지도 탐색 시작점은 상단 검색 바이며, 카테고리 칩은 검색 바 아래의 단일 가로 행으로 제한한다.
- **Route 적용 원칙:** 보라색은 현재 위치·선택된 장소·주요 CTA에만 쓰고, 지도 자체는 밝고 저채도의 베이지·세이지 톤으로 두어 여행 기록의 사진과 정보가 돋보이게 한다.
