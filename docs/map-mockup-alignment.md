# Route 지도 시안 정렬 기록

승인된 A안은 지도 탐색을 먼저 보여주고, 검색과 장소 정보는 지도 위에 단계적으로 겹쳐 두는 구조다. 이에 맞춰 Route 지도 탭을 일반적인 상·하 분할 레이아웃에서 **지도 중심 오버레이 레이아웃**으로 변경했다.

| 항목 | 기존 화면 | 승인 시안 기준 | 반영 결과 |
|---|---|---|---|
| 검색 바 | 지도 바깥의 흰 상단 영역 | 지도 위 상단의 큰 둥근 검색 바 | 실제 지도 위에 떠 있는 48px 검색 바로 변경 |
| 카테고리 | 검색 바 아래 일반 행 | 검색 바 바로 아래의 흰 칩 | 지도 위 오버레이 칩으로 변경 |
| 지도 비율 | 상단 UI와 시트 사이에서 축소 | 화면의 중심을 크게 차지 | 지도 컨테이너를 전체 화면 기반으로 확장 |
| 장소 마커 | 숫자 원형 마커 | 보라·핑크 색상의 핀 | 실제 Google 지도에도 핀 형태 SVG 마커 적용 |
| 장소 시트 | 지도 아래 별도 패널 | 지도 하단을 덮는 둥근 카드 | 하단 오버레이 시트로 변경하고 사진·평점·거리의 카드 밀도 보정 |

기본 상태는 장소 두 개가 보이는 미리보기 시트이며, 위로 끌면 결과 목록이 확장된다. 아래로 내리면 시트가 사라져 검색 바와 지도 탐색에 집중할 수 있다.
