# Route 지도 화면 시안 선택 가이드

## 시안 비교

| 시안 | 핵심 구조 | 강점 | Route에 적합한 상황 |
|---|---|---|---|
| A. 탐색 우선 | 상단 검색 바, 카테고리 칩, 비모달 하단 장소 시트 | 처음 방문한 사용자가 주변 장소를 빠르게 발견하기 쉽다. | 지도 메인의 기본 화면 |
| B. 코스 우선 | 번호 마커, 경로 선, 이동 시간, 코스 요약 카드 | 장소를 모아 실제 일정으로 만드는 Route의 핵심 가치를 가장 명확하게 보여준다. | 코스 생성 2~4단계와 코스 상세 |
| C. 저장 우선 | 선택 장소의 사진 프리뷰, 저장 장소 카드, 코스 추가 CTA | 발견한 장소를 저장하고 재활용하는 흐름을 감성적으로 강조한다. | 장소 상세 진입 직전과 저장 장소 탐색 |

## 권장 조합

Route의 지도 탭 기본값은 **A. 탐색 우선**으로 구성한다. 사용자가 장소를 선택했을 때는 C의 사진 프리뷰 카드로 전환하고, 두 곳 이상을 코스에 추가한 이후에는 B의 경로 카드와 번호 마커를 표시한다. 이 조합은 “발견 → 저장 → 코스 제작” 흐름을 화면 전환 없이 자연스럽게 유지한다.

## 생성 시안 검수 메모

생성 완료된 **B안**은 번호 마커·보라색 경로선·구간별 이동 시간·하단 일정 요약을 명확하게 보여주므로 코스 편집과 코스 상세에 적합하다. **C안**은 선택 장소의 사진 프리뷰와 저장 장소 캐러셀, 코스 추가 CTA가 잘 드러나 장소 발견 및 저장 흐름에 적합하다. 두 시안 모두 Route의 보라색 강조와 밝은 지도 기반 정보 구조를 유지했으며, 실제 구현에서는 iPhone 프레임과 장식용 시스템 바를 제외하고 앱 콘텐츠 구조만 채택한다.

## 구현 순서

| 우선순위 | 컴포넌트 | 구현 내용 |
|---|---|---|
| 1 | `MapSearchBar` | 상단 고정 검색 바, 현재 위치 버튼, 카테고리 칩 한 줄 |
| 2 | `PlaceMapMarker` | 일반·선택·저장됨 상태를 구분하는 장소 마커 |
| 3 | `NearbyPlacesSheet` | 드래그 가능한 비모달 하단 시트와 축소·확장 상태 |
| 4 | `SelectedPlacePreview` | 사진, 평점, 저장, 코스 추가가 포함된 선택 장소 프리뷰 |
| 5 | `CourseRouteMap` | 번호 마커, 경로 폴리라인, 구간별 예상 소요 시간 |
