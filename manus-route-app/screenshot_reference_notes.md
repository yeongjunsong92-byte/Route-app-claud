# Route GPT 시안 재현 기준

첨부 시안은 390px 전후의 모바일 프레임을 기준으로 하며, 전체 분위기는 흰색·연한 회색 바탕과 보라색 주요 액션 컬러를 사용한다. 하단 네비게이션은 홈, 지도, 코스, 마이의 4개 탭으로 구성되고 선택 상태는 보라색 아이콘과 텍스트로 강조된다.

지도 섹션은 검색창, 카테고리 필터 칩, 큰 지도 영역, 장소 리스트 순서로 배치된다. 장소 리스트는 썸네일, 장소명, 별점과 리뷰 수, 카테고리·거리 정보를 가진 카드형 행으로 표현한다. 장소 상세는 지도 위에 이미지와 장소 정보 카드가 올라오며, 하단에 저장과 코스 추가 버튼이 있다. 저장 버튼은 바텀시트를 열고 내 장소 저장, 새 코스 만들기, 기존 코스에 추가의 선택지를 제공한다.

코스 생성 시안은 상단 진행 표시와 4개 단계로 구성된다. 1단계는 코스명 설정, 2단계는 지도와 장소 목록을 통한 장소 추가, 3단계는 장소별 방문 시간·체류 시간·예상 비용·메모 입력, 4단계는 시간순 타임라인과 총 비용을 확인한 뒤 저장하는 구조다. 코스 상세는 지도 위에 경로를 표시하고, 번호가 있는 색상 마커와 시간순 장소 카드로 흐름을 보여준다.

재현 작업의 우선순위는 기능을 새로 해석하는 것이 아니라, 위의 프레임·간격·보라색 버튼·둥근 카드·하단 고정 네비게이션·바텀시트·4단계 스텝 구조를 시안과 동일하게 유지하는 것이다.
